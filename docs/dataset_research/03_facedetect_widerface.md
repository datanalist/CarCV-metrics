# Аналоги датасета «WIDER FACE» для задачи «Face Detection — детекция лиц»

> **См. также:** исходный датасет — [wider_face.md](../about_datasets/wider_face.md) · индекс датасетов — [datasets.md](../../datasets.md) · сводка исследования — [00_SUMMARY.md](00_SUMMARY.md)

## Контекст и требования

**Целевая модель:** FaceDetect / FaceNet (NVIDIA TAO, архитектура DetectNet_v2). Один класс «face», выход — axis-aligned bbox, фиксированный вход **736×416**. В CARS детектор лиц питает требование FR-06 (сохранение кропов лиц), поля БД `face_count` / `face_coords` и артефакты `face_images/{track_id}.bmp`.

**Исходный датасет:** WIDER FACE (32 203 изображения, 393 703 лица, 61 категория событий, деление Easy/Medium/Hard). Лицензия **CC BY-NC-ND 4.0** — некоммерческая и без производных. Для CARS (коммерческий продукт) это означает: WIDER FACE допустим только как **внутренний research-бенчмарк**, а в коммерческий пайплайн/поставку/маркетинг — нельзя без отдельного разрешения правообладателя. Это и есть главная причина искать коммерчески-чистые аналоги.

**Что нужно от аналога (под бортовой POV CARS — дистанция 5–50 м, угол 0–30°, day/night/IR):**
- bbox-разметка лиц, легко приводимая к 1 классу «face» и формату TAO/DetectNet_v2 (KITTI/COCO/VOC);
- по возможности — **коммерчески разрешённая лицензия** (приоритет для продукта);
- закрытие пробелов WIDER FACE: ночь / низкая освещённость, погодные и оптические деградации, окклюзия лица;
- для метрик — желательно устоявшийся протокол (Easy/Medium/Hard либо ROC).

> **О face embedding.** Модель эмбеддинга лиц в стеке CARS пока отсутствует (`None (Trainable)`). Все датасеты ниже — это датасеты **детекции** лиц: они НЕ содержат меток идентичности персон. Сам WIDER FACE по той же причине **не годится** для обучения/оценки эмбеддингов, и ни один из перечисленных аналогов эту задачу не закрывает — для эмбеддинга понадобится отдельный датасет с identity-метками (например, из семейства LFW/MS-Celeb/VGGFace), когда модель появится.

> **Дисклеймер по лицензиям.** Для всех датасетов, где первоисточник не объявляет явной лицензии, статус коммерческого использования трактуется по умолчанию как **restricted/unclear** («не подтверждено», а не «запрещено»). Перед любым коммерческим применением обязателен legal review и/или прямой запрос правообладателю. Ни один из найденных аналогов не покрывает истинный бортовой POV «через лобовое стекло» и настоящий IR-канал — для этих сценариев потребуется собственный сбор данных.

## Обзор аналогов

### Open Images V7 — класс «Human face» (bbox-подмножество)
**Год / Объём / Лицензия (комм.: да — аннотации; unclear — изображения) / Формат / Домен:** 2022 (V7; класс с V4/2018) / ~9 млн изображений всего, 600 классов, ~16 млн bbox; «Human face» — подтверждённый boxable-класс (№264 в перечне классов V7), точное число bbox именно для лиц первоисточником в явном виде НЕ подтверждено / bbox (x1,y1,x2,y2), иерархия классов / web (Flickr, бытовые/уличные/студийные сцены).

- **Плюсы:**
  - Аннотации лицензированы Google LLC под **CC BY 4.0** — коммерческое использование разметки разрешено (критично для CARS).
  - Огромный объём и разнообразие сцен/масштабов/поз/освещения — хорош для дообучения детектора 1 класса «face».
  - Готовая bbox-разметка, можно выгрузить ТОЛЬКО класс «Human face» через официальный downloader, FiftyOne или Ultralytics; легко конвертируется под TAO/DetectNet_v2.
- **Минусы:**
  - Лицензия самих изображений заявлена как CC BY 2.0, но Google **прямо снимает гарантии** по лицензии каждого конкретного файла («we make no representations or warranties… verify the license for each image yourself») — для продукта нужен поштучный legal review лицензий изображений.
  - Точное число bbox для «Human face» не подтверждено первоисточником.
  - Лицо — не приоритетный класс Open Images: body-parts намеренно НЕ размечены на ~80% train; полнота/качество разметки лиц ниже специализированных face-датасетов, нужна чистка/ремаппинг (порог мин. размера, частично видимые лица).
  - Нет automotive POV «через стекло», нет выделенного IR/ночного среза.
- **Применимость для валидации:** условно — как вторичный кросс-доменный (коммерчески-чистый) чек. НЕ эталонный face-бенчмарк: нет деления Easy/Medium/Hard, не сопоставим с WIDER_val по метрикам.
- **Применимость для обучения:** **основной кандидат для дообучения** FaceDetect под коммерцию — отфильтровать «Human face», привести bbox к формату TAO, отсеять микро-лица. Перед поставкой — legal review лицензий изображений.

### DARK FACE — Face Detection in Low Light (UG2+ Challenge)
**Год / Объём / Лицензия (комм.: unclear) / Формат / Домен:** 2019 / 6 000 размеченных (train/val) + 4 000 test (bbox у организаторов) + ~9 000 неразмеченных; ~50 399 bbox лиц на размеченной части / bbox (x1,y1,x2,y2), 1 класс «face» / ночные/низкоосвещённые реальные уличные сцены (улицы, мосты, корпуса, парки).

- **Плюсы:**
  - Закрывает **ночь / низкую освещённость** — ключевой пробел WIDER FACE для CARS.
  - bbox-формат, 1 класс «face» — ложится на FaceDetect/DetectNet_v2 без переразметки.
  - Реальные (не синтетические) ночные уличные сцены, релевантны патрульному/парковочному сценарию ночью.
  - ~50k bbox — достаточно для оценки и частичного дообучения под ночь.
- **Минусы:**
  - **Лицензия на сайте проекта НЕ объявлена** (подтверждено: страница даёт только ссылки на скачивание, без license/usage terms) → коммерческое использование под вопросом, нужен запрос организаторам.
  - Только видимый спектр при низком свете — это **НЕ настоящий IR**; IR-канал FaceDetect датасетом не покрывается.
  - Сильное смещение распределения в очень тёмные кадры — нерепрезентативно для дневных сцен.
  - bbox для test недоступны публично (оценка через challenge); работаем с train/val.
- **Применимость для валидации:** рекомендуется как отдельный **NIGHT/low-light срез** для FaceDetect, метрики считать отдельно от дневного бенчмарка.
- **Применимость для обучения:** кандидат для дообучения под ночь (1 класс face, bbox) — после уточнения лицензии для коммерции.

### UFDD — Unconstrained Face Detection Dataset
**Год / Объём / Лицензия (комм.: unclear) / Формат / Домен:** 2018 / 6 424 изображения, 10 895 аннотаций лиц (+ дистракторы без лиц) / bbox в стиле WIDER FACE, 1 класс «face» + категории деградаций / web с намеренными деградациями (дождь, снег, дымка, motion/focus-блюр, вариации освещения, помехи объектива).

- **Плюсы:**
  - Покрывает **погодные и оптические деградации** (rain/snow/haze/blur/illumination) — близко к реальным помехам бортовой камеры.
  - Формат разметки совместим с WIDER FACE → переиспользуется парсер/метрики.
  - Наличие **дистракторов** (кадры без лиц) — тест на ложные срабатывания, важно для FR-06.
- **Минусы:**
  - Лицензия не объявлена; изображения из источников со смешанными правами (Google/Bing/Flickr/Pixabay/Unsplash/Wikimedia/Baidu) → коммерция рискованна, нужен legal review.
  - Малый объём (6 424 изобр.) — это бенчмарк, не обучающий корпус.
  - Web-домен, не automotive POV; нет IR/ночи; нет официального Easy/Medium/Hard (оценка по категориям деградаций).
- **Применимость для валидации:** хороший доп. срез на погодные/оптические деградации и на ложные срабатывания (ближе к помехам бортовой камеры, чем чистый WIDER FACE). Внутренний research до legal review.
- **Применимость для обучения:** малопригоден (мал по объёму) — использовать как hard-валидацию/стресс-тест.

### Face Mask Detection (andrewmvd, Kaggle)
**Год / Объём / Лицензия (комм.: да) / Формат / Домен:** 2020 / 853 изображения, 3 класса (with_mask / without_mask / mask_weared_incorrect), ~4 072 объекта / bbox в PASCAL VOC XML / web, уличные и бытовые фото людей в масках и без.

- **Плюсы:**
  - **CC0 1.0 (Public Domain)** — полностью свободно, в т.ч. коммерчески, без атрибуции и legal-рисков по лицензии.
  - Готовый VOC bbox-формат, тривиально конвертируется под 1 класс «face» (ремап классов масок).
  - Покрывает окклюзию маской — полезно для устойчивости детектора.
- **Минусы:**
  - Очень мал (853 изобр.) — недостаточно для самостоятельного обучения, только augmentation.
  - Перекос в маски/COVID-тематику; bbox размечают «лицо в маске», а не общий класс лиц.
  - Web-домен, не automotive; нет IR/ночи; разметка любительская (Kaggle), нужна проверка.
- **Применимость для валидации:** маленький коммерчески-чистый санити-чек на окклюзию масками; не эталонный бенчмарк.
- **Применимость для обучения:** **коммерчески-чистая малая добавка** к обучающей выборке (ремап в 1 класс «face»), особенно под устойчивость к маскам. Сам по себе мал.

### FDDB — Face Detection Data Set and Benchmark (UMass)
**Год / Объём / Лицензия (комм.: нет) / Формат / Домен:** 2010 / 2 845 изображений, 5 171 лицо / **эллипсы** (major/minor axis, угол, центр) — НЕ bbox / web / новостные фото (Faces in the Wild).

- **Плюсы:**
  - Классический эталон face detection в неконтролируемых условиях; устоявшийся протокол оценки (ROC, discrete/continuous) и devkit.
  - Небольшой и удобный для быстрой валидации; вариативность позы/окклюзии/освещения.
- **Минусы:**
  - Аннотации — **эллипсы**, не bbox: нужна конвертация эллипс→axis-aligned bbox; IoU по bbox не идентичен оригинальному протоколу.
  - **Коммерческое использование закрыто:** первоисточник/зеркала указывают «educational and informational purposes only»; изображения — новостные фото (Faces in the Wild) → для продукта непригоден без согласования.
  - Маленький (2 845 изобр.), старый (2010), низкое разрешение; нет IR/ночи; нет automotive-сцен.
- **Применимость для валидации:** доп. лёгкий бенчмарк детектора (после конвертации эллипс→bbox), только внутренний research; для коммерческих выводов — нет.
- **Применимость для обучения:** не рекомендуется (мал, формат эллипсов, лицензия educational-only).

### MAFA — MAsked FAces dataset
**Год / Объём / Лицензия (комм.: unclear) / Формат / Домен:** 2017 / 30 811 изображений, 35 806 лиц с масками/окклюзиями / bbox лица + bbox глаз/маски, ориентация лица, степень и тип окклюзии / web (лица, закрытые масками, шарфами, руками).

- **Плюсы:**
  - Крупнейший специализированный набор по **окклюзированным лицам** (~31k изобр.) — сценарий частично закрытого лица водителя/пассажира.
  - Богатые атрибуты окклюзии/типа маски → точный срез качества по occlusion; bbox лица конвертируется под 1 класс «face».
- **Минусы:**
  - Лицензия правообладателем не объявлена; интернет-изображения → коммерция под вопросом, legal review.
  - Сильный перекос в маски — нерепрезентативно для общего распределения лиц; нет automotive POV / IR / ночи; нужна чистка/ремаппинг.
- **Применимость для валидации:** полезен как срез на **окклюзию** для FaceDetect; внутренний research до подтверждения лицензии.
- **Применимость для обучения:** возможен как доп. данные для устойчивости к окклюзиям при дообучении, с осторожностью (перекос в маски) и после legal review.

### MALF — Multi-Attribute Labelled Faces
**Год / Объём / Лицензия (комм.: unclear) / Формат / Домен:** 2015 / 5 250 изображений, ~11 931 лицо / квадратный bbox + yaw/pitch/roll, пол, очки, окклюзия, ignore-флаг для лиц <20×20 / web (Flickr/Baidu, неконтролируемые условия).

- **Плюсы:**
  - Богатые атрибуты позы/окклюзии → детальный fine-grained срез качества детектора; корректный ignore-протокол для микро-лиц.
- **Минусы:**
  - Лицензия не объявлена, источники со смешанными правами → коммерция под вопросом; мал (5 250 изобр.); доступ через CASIA по запросу (стабильность зеркал вариативна); нет automotive/IR/ночи.
- **Применимость для валидации:** доп. fine-grained срез (поза/окклюзия) с корректным ignore; внутренний research до legal review.
- **Применимость для обучения:** не рекомендуется (мал, доступ по запросу).

## Рекомендации

**Валидация (приоритет по убыванию):**
1. **Эталон оставить WIDER_val** (Easy/Medium/Hard) для сопоставимости с литературой — но только внутренне (NC-лицензия).
2. **DARK FACE — primary доп. срез на ночь/low-light** (главный пробел WIDER FACE под CARS), метрики считать отдельно от дневного бенчмарка.
3. **UFDD — secondary** срез на погодные/оптические деградации + дистракторы (тест ложных срабатываний для FR-06).
4. **MAFA / MALF — marginal** fine-grained срезы на окклюзию/позу.
5. **FDDB — research-only** лёгкий бенчмарк (educational-only лицензия + конвертация эллипс→bbox); для коммерческих выводов не использовать.

**Обучение / дообучение под коммерцию (приоритет):**
1. **Open Images V7 «Human face» — основной кандидат.** Единственный с коммерческой лицензией аннотаций (CC BY 4.0) и большим объёмом; отфильтровать класс «Human face», ремап в 1 класс «face», отсечь микро-лица, привести bbox к TAO. **Обязателен поштучный legal review лицензий изображений** (Google гарантий не даёт).
2. **Face Mask Detection (andrewmvd, CC0) — коммерчески-чистая малая добавка** под устойчивость к окклюзии масками.
3. **DARK FACE — для дообучения под ночь**, но только после уточнения лицензии у организаторов UG2+.

**Сквозные оговорки:**
- Точное число face-bbox в Open Images первоисточником не подтверждено.
- DARK FACE / UFDD / MAFA / MALF — «unclear» означает «не подтверждено» (нет явной лицензии), а не «запрещено»; FDDB — явно educational-only (коммерция закрыта).
- Ни один аналог не покрывает истинный бортовой POV «через стекло» и настоящий IR-канал — для этих сценариев нужен **собственный сбор данных**.
