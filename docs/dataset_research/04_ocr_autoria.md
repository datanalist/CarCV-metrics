# Аналоги датасета «autoriaNumberplateOcrRu-2021-09-01» для задачи «OCR — распознавание текста номерных знаков»

> **См. также:** исходный датасет — [autoria_numberplate_ocr_ru.md](../about_datasets/autoria_numberplate_ocr_ru.md) · индекс датасетов — [datasets.md](../../datasets.md) · сводка исследования — [00_SUMMARY.md](00_SUMMARY.md)

> Документ подготовлен в рамках исследования открытых датасетов-аналогов стека CARS (коммерческий продукт). Все ключевые факты по лицензиям/доступности перепроверены адверсариально по первоисточникам (LICENSE-файлы, индекс `nomeroff.net.ua/datasets/`, карточки HuggingFace, arXiv). Где факт не удалось подтвердить первоисточником — снижена уверенность и явно проставлена пометка.
>
> **Юридическая дисциплина:** для поставляемой модели CARS пригодны ТОЛЬКО датасеты с явной коммерчески-совместимой лицензией (CC BY 4.0, MIT, Apache-2.0). По умолчанию лицензия считается `restricted/unclear`, пока обратное не подтверждено первоисточником. Любой `NC` (NonCommercial) или `ND` (NoDerivatives) или «research-only» блокирует коммерческое использование и/или дообучение-распространение производной модели.

## Контекст и требования

**Целевая модель:** `nomeroff_ocr` — CRNN на бэкбоне ResNet18 (чекпойнт `anpr_ocr_ru_2023_02_01_resnet18.ckpt`), OCR номеров РФ. Вход ~188×48×3 RGB, выход — строка номера, декодируется CTC. Алфавит — ГОСТ-Р 50577 (22 содержательных символа: `0–9` + 12 латинских литер `A B E K M H O P C T Y X`, визуально идентичных кириллическим А/В/Е/К/М/Н/О/Р/С/Т/У/Х). Целевые метрики §6.4: **Full Plate Accuracy > 0.85**, **Character Accuracy > 0.92**.

**Исходный датасет** `autoriaNumberplateOcrRu-2021-09-01` (Nomeroff Net / AUTO.RIA, CC BY 4.0, 57 120 кропов, формат `ann/`(JSON)+`img/`(PNG), эталон в поле `description`). Это **первоисточник обучения** RU-OCR Nomeroff Net, поэтому при использовании его и любых производных корпусов для валидации существует риск **train-leakage** (оптимистическое смещение метрик).

**Что требуется от аналога:**
- **Формат:** кропы пластин с текстовым эталоном номера (filename или поле в JSON), желательно — полные кадры с bbox/4 углами для end-to-end.
- **Алфавит:** RU-ГОСТ кириллица-как-латиница; смешанные алфавиты СНГ допустимы как доменное расширение.
- **Домен-fit:** ближе к бортовому сценарию CARS (1920×1080, day/night/IR, дистанция/угол) — выше ценность; чистые кропы валидируют только OCR-ступень, не детекцию.
- **Лицензия:** обязательно коммерчески-совместимая для поставляемой модели.
- **Независимость:** для честной валидации — held-out, не входивший в обучающий корпус Nomeroff.

> **Замечание по смежной задаче face-embedding (для единообразия исследования стека CARS):** датасет **WIDER FACE** содержит только bbox лиц **без identity-меток**, поэтому он НЕ годится для обучения/валидации эмбеддингов лиц (нет пар «тот же / другой человек»); WIDER FACE применим исключительно к задаче детекции лиц, а не к metric-learning эмбеддингов. К задаче OCR номеров это не относится напрямую, но фиксируется как общий принцип отбора аналогов.

## Обзор аналогов

### Nomeroff Net OCR — мультирегиональные пакеты (autoriaNumberplateOcr Ua/Eu/Kz/By/Ge/Am/Su/Md/Kg + Ru-Military)
**Год / Объём / Лицензия (комм.: да) / Формат / Домен:** 2019–2025 (снимки по датам) / десятки архивов, по региону тысячи–десятки тысяч кропов (RU-эталон = 57 120) / **CC BY 4.0** (тот же `license.txt` каталога AUTO.RIA Numberplate Dataset) / OCR-only, один JSON на кроп, эталон в поле `description`, без bbox (идентично исходному RU) / кропы пластин (выход детектора), фото объявлений AUTO.RIA + community.

**Проверено (2026-06-05):** индекс `https://nomeroff.net.ua/datasets/` подтверждает наличие OCR-архивов по регионам **Ua, Eu (2023-01-30/04-25/06-26), Kz (2019-04-26, 2022-11-29), By (2020-10-09, 2021-08-27), Ge (2019-07-06, 2022-11-29), Am (2021-05-20, 2022-11-21), Su (2021-09-03, 2023-01-31, 2023-03-10), Md (2022-07-01, 2023-01-27), Kg (2022-11-30)** и **двух Ru-Military-архивов**: `autoriaNumberplateOcrRu-Military-2022-03-24.zip`, `autoriaNumberplateOcrRu-Military-2022-03-25.zip`. Прямая загрузка по HTTP работает (Ru-Military-архив отдаётся как крупный бинарник).

- **Плюсы:**
  - Тот же формат аннотаций (`description` в JSON), что и исходный RU-датасет — нулевая стоимость интеграции, готовый загрузчик подходит.
  - **CC BY 4.0** — безопасно для коммерческого CARS (требуется только атрибуция).
  - Содержит кириллицу/смешанные алфавиты соседних регионов (kz/by/su/kg/md) + Ru-Military — расширяет домен за пределы стандартного ГОСТ-Р 50577.
  - Прямые HTTP-архивы без email-запроса; `autoriaNumberplateOcrRu-Military-2022-*` — независимый held-out RU-материал на спецсериях.
- **Минусы:**
  - НЕ чистый RU-ГОСТ-алфавит: eu/ge — латиница иных форматов → потребуется расширение/смена словаря CTC при обучении на этих регионах.
  - **Риск train-leakage:** это родной корпус Nomeroff Net; RU-веса `nomeroff_ocr` могли видеть часть данных. Для честной валидации брать регионы/снимки, заведомо не входившие в обучение (Ru-Military, свежие Ua/СНГ).
  - Объёмы по регионам в индексе явно не указаны — требуется скачивание и инвентаризация.
  - Только кропы, нет полных кадров — не валидирует end-to-end и детекцию.
- **Применимость для валидации:** Да — как независимый held-out (особенно **Ru-Military** и свежие снимки регионов СНГ для проверки кириллицы и устойчивости).
- **Применимость для обучения:** Да — дообучение/доменное расширение RU + соседние регионы; для не-RU алфавитов нужна адаптация словаря.
- **Рекомендация:** **primary** · уверенность: **high**.

### AY000554/Car_plate_OCR_dataset (HuggingFace)
**Год / Объём / Лицензия (комм.: да) / Формат / Домен:** производный от Nomeroff/AUTO.RIA (~2021) / **45 514 кропов** RU (train 37 775 / val 4 891 / test 2 845) / **CC BY 4.0** (подтверждено карточкой HF) / OCR-only, имя файла = текст номера (напр. `A129XY196.jpg`), без bbox, алфавит `1234567890ABEKMHOPCTYX` (22 символа ГОСТ-Р 50577) / кропы RU-пластин (очищенный производный), JPEG.

**Проверено (2026-06-05):** карточка HF доступна; лицензия CC BY 4.0 и объём 45 514 подтверждены дословно («Оригинальный датасет распространяется под лицензией CC BY 4.0»).

- **Плюсы:**
  - Точное соответствие целевому ГОСТ-алфавиту `nomeroff_ocr` (22/22 символа).
  - **CC BY 4.0** — коммерчески безопасно при атрибуции.
  - Лёгкая интеграция: эталон = stem имени файла, JPEG/RGB (без неоднородности RGBA исходника); доступ через HF Datasets API; уже описан в репозитории CARS (`car_plate_ocr_dataset_ru.md`).
  - Готовый train (37 775) для дообучения и val+test (7 736) для бенчмарка.
- **Минусы:**
  - Производный от того же корпуса Nomeroff/AUTO.RIA, что и обучающий → **ВЫСОКИЙ риск train-leakage** с `nomeroff_ocr`; не даёт честную независимую валидацию.
  - Беднее метаданными исходника (нет `region_id`/`state_id`/`count_lines`/`size`, нет bbox).
  - Только стандартные гражданские номера; нет спецсерий/двухстрочных.
  - Только кропы — не валидирует детекцию и end-to-end.
- **Применимость для валидации:** условно — val+test как вторичный бенчмарк, но из-за пересечения корпусов метрики оптимистично смещены; не основной held-out.
- **Применимость для обучения:** Да — удобный готовый train для дообучения OCR на чистом ГОСТ-алфавите.
- **Рекомендация:** **secondary** · уверенность: **high**.

### CCPD / CCPD2019 + CCPD-Green (CCPD2020) — Chinese City Parking Dataset
**Год / Объём / Лицензия (комм.: да) / Формат / Домен:** 2018 (ECCV), обновления 2019/2020 / **300 000+ изображений** (подмножества DB/Blur/FN/Rotate/Tilt/Challenge/Weather + CCPD-Green 8-символьные) / **MIT** (подтверждено файлом `LICENSE` в `detectRecog/CCPD`) / аннотации в имени файла: area ratio, наклоны, bbox, 4 вершины пластины, индексы символов, яркость/размытость; полные кадры + bbox/keypoints + текст; алфавит — китайские провинции (34) + латиница (A–Z без I,O) + цифры / парковочные камеры Китая, дневная съёмка, реальные кадры.

**Проверено (2026-06-05):** `LICENSE` в репозитории `detectRecog/CCPD` — стандартный текст **MIT License** (подтверждено напрямую). Объём 300k+ подтверждён.

- **Плюсы:**
  - **MIT** — максимально либеральная коммерческая лицензия, прямое скачивание без email.
  - Огромный объём (300k+) и богатые аннотации: bbox + 4 угла + текст + параметры наклона/качества.
  - Подмножества по сложности (Blur/Rotate/Tilt/Challenge/Weather) — для стресс-тестов устойчивости OCR-пайплайна.
  - Полные кадры — для end-to-end и отработки выравнивания пластины перед OCR.
- **Минусы:**
  - Алфавит НЕ RU-кириллица (китайские провинции + латиница) — прямой валидации `nomeroff_ocr` нет; применим лишь как стресс на геометрию или по латинской части.
  - Для обучения RU-OCR прямой пользы мало (иной словарь); ценность методологическая (аугментации, выравнивание).
  - Домен Китая, не СНГ; большие архивы — качество скачивания зависит от зеркал.
- **Применимость для валидации:** косвенно — стресс-тест устойчивости детектора/выравнивания и латинской части OCR; НЕ для метрик RU-точности.
- **Применимость для обучения:** ограниченно — источник кропов для предобучения CRNN на латинице/цифрах или для аугментаций геометрии; не для RU-словаря.
- **Рекомендация:** **marginal** · уверенность: **high**.

### Kaggle «Nomeroff Russian license plates» (evgrafovmaxim)
**Год / Объём / Лицензия (комм.: unclear) / Формат / Домен:** производный от AUTO.RIA/Nomeroff (Kaggle-зеркало) / объём не подтверждён первоисточником / **лицензия НЕ подтверждена** (страница за логином) / по описанию зеркала — фото RU-пластин с CSV-метаданными (plate_number, vehicle_type, angle_of_view, weather, time_of_day, occlusion) / RU-пластины в разных условиях.

**Проверено (2026-06-05):** Kaggle-страница требует авторизации — лицензию подтвердить не удалось. Сторонний агрегатор-зеркало (gts.ai) указывает наличие OCR-меток текста (`plate_number`) и контекстных полей, но лицензию/коммерческую совместимость НЕ подтверждает. Считаем лицензию `unclear` до ручной проверки на Kaggle.

- **Плюсы:**
  - RU-домен, потенциально разнообразные условия (day/night, погода) — ближе к сценарию CARS, чем чистые кропы.
  - По описанию зеркала есть OCR-метки текста и метаданные угла/времени/погоды — если подтвердится, ценный RU-аналог с домен-разметкой.
- **Минусы:**
  - **Лицензия не подтверждена первоисточником** — нельзя гарантировать коммерческую совместимость (по умолчанию `restricted`).
  - Возможный train-leakage (тот же корпус Nomeroff/AUTO.RIA).
  - Объём и точный формат меток не верифицированы; требуется ручная проверка на Kaggle.
- **Применимость для валидации:** условно — только после ручной проверки лицензии и формата на Kaggle; иначе не использовать в коммерческих метриках.
- **Применимость для обучения:** условно — лишь после подтверждения CC-совместимой лицензии и наличия OCR-меток.
- **Рекомендация:** **marginal** · уверенность: **low**.

### Global License Plate Dataset (GLPD, siddagra)
**Год / Объём / Лицензия (комм.: нет) / Формат / Домен:** 2024 (arXiv:2405.10949) / **5 000 000+ изображений из 74 стран** (~43.9 GB) / **CC BY-NC-ND 4.0** (подтверждено arXiv-страницей) / текст символов + маски сегментации + 4 вершины + vehicle make/colour/model; полные сцены / мульти-страновой, смешанные источники.

**Проверено (2026-06-05):** arXiv подтверждает 5M+/74 страны и лицензию **CC BY-NC-ND 4.0**. **Новый факт:** HuggingFace-страница датасета (`siddagra/Global-Licenseplate-Dataset`) сейчас возвращает **HTTP 401** — доступ гейтован/требует авторизации, что дополнительно ухудшает доступность.

- **Плюсы:**
  - Огромный масштаб (5M+) и 74 страны — потенциально содержит RU/СНГ-пластины.
  - Богатые аннотации: текст + маски + углы + атрибуты ТС.
  - Свежий (2024), позиционируется как бенчмарк для finetuning.
- **Минусы:**
  - **CC BY-NC-ND 4.0:** NC = некоммерческое (несовместимо с продуктом CARS) И ND = запрет производных (нельзя дообучать/распространять производную модель).
  - **ND особенно критичен:** дообучение OCR = производная работа → запрещено к распространению.
  - Доступ к HF гейтован (401) — дополнительный барьер.
  - Алфавиты не разделены под RU-ГОСТ; нужна фильтрация RU-подмножества; неоднородность по странам.
- **Применимость для валидации:** только внутренний research-бенчмарк (некоммерчески); для поставляемой модели CARS НЕ годится.
- **Применимость для обучения:** запрещено для CARS (NC+ND блокируют коммерческое дообучение и распространение).
- **Рекомендация:** **not_recommended** · уверенность: **high**.

### RodoSol-ALPR
**Год / Объём / Лицензия (комм.: нет) / Формат / Домен:** 2022 (VISAPP, Laroca et al.) / **20 000 изображений** (5k авто BR + 5k мото BR + 5k авто Mercosur + 5k мото Mercosur) / **research-only / non-commercial** (custom-соглашение, доступ по email с университетского адреса) / TXT на изображение: тип ТС, layout, текст номера + (x,y) 4 углов; полные кадры; латиница+цифры / стационарные камеры платных трасс (Бразилия/Mercosur).

- **Плюсы:**
  - Качественные аннотации: текст + 4 угла + полные кадры — хорошо для выравнивания и end-to-end.
  - Реальный дорожный домен, авто и мотоциклы, разные layout'ы; частый кросс-датасет-бенчмарк.
- **Минусы:**
  - **КОММЕРЧЕСКОЕ использование ЗАПРЕЩЕНО** — несовместимо с CARS; только внутренний research.
  - Доступ по email с .edu/.ac + подписанное соглашение — барьер.
  - Алфавит латинский BR/Mercosur, не RU-кириллица; не СНГ-домен.
- **Применимость для валидации:** только внутренний research (кросс-датасет проверка латинского OCR); нельзя в коммерческих метриках.
- **Применимость для обучения:** не рекомендуется для CARS (non-commercial).
- **Рекомендация:** **not_recommended** · уверенность: **high**.

### UFPR-ALPR
**Год / Объём / Лицензия (комм.: нет) / Формат / Домен:** 2018 (IJCNN, Laroca et al.) / **4 500 кадров** (150 ТС × 30 кадров), Бразилия / **research-only / non-commercial** (academic-соглашение, доступ по университетскому email) / TXT: bbox ТС и пластины, позиции символов, текст; полные кадры (камера и ТС в движении); латиница+цифры / съёмка с движущегося автомобиля.

- **Плюсы:**
  - Уникальный **бортовой сценарий** (и камера, и ТС в движении) — ближе всего к use-case CARS по динамике/геометрии.
  - Подробные аннотации; пригоден для оценки устойчивости к motion blur; эталонный ALPR-бенчмарк.
- **Минусы:**
  - **КОММЕРЧЕСКОЕ использование ЗАПРЕЩЕНО** (academic-only) — вне research несовместимо с CARS.
  - Доступ по email-соглашению; латинский алфавит BR (нет RU-валидации); малый объём, один домен.
- **Применимость для валидации:** только внутренний research (устойчивость к движению/motion blur); не коммерческие метрики.
- **Применимость для обучения:** не рекомендуется для CARS (non-commercial).
- **Рекомендация:** **not_recommended** · уверенность: **high**.

## Рекомендации

**Приоритет для валидации (честный held-out, коммерчески чистый):**
1. **Nomeroff Ru-Military-2022 + свежие снимки регионов СНГ** (`primary`, CC BY 4.0) — независимый от RU-обучения материал, идентичная интеграция, проверяет устойчивость кириллицы/спецсерий без train-leakage. Это лучший доступный честный held-out.
2. **Собственные собранные кадры CARS** (вне данного списка) — единственный гарантированно независимый источник для финальных продуктовых метрик end-to-end; рекомендуется как эталонная привязка.
3. `AY000554` val+test (7 736) — только как **вторичный** бенчмарк; результаты трактовать осторожно из-за пересечения корпусов (leakage), не как независимую оценку.
4. **CCPD** — только стресс-тест геометрии/выравнивания и латинской части, НЕ для RU-метрик точности.

**Приоритет для дообучения (коммерчески разрешённое расширение):**
1. **Nomeroff мультирегиональные OCR-пакеты** (CC BY 4.0) — RU + соседние регионы СНГ; для не-RU алфавитов (eu/ge) потребуется расширение словаря CTC.
2. **AY000554 train (37 775)** (CC BY 4.0) — готовый чистый ГОСТ-алфавит для дообучения RU-OCR.
3. **CCPD** — ограниченно, как источник кропов для предобучения CRNN на цифрах/латинице и для аугментаций геометрии (не для RU-словаря).

**Категорически НЕ использовать в поставляемой модели CARS:** GLPD (NC+ND — запрет коммерции и распространения производной), RodoSol-ALPR и UFPR-ALPR (non-commercial academic). Эти датасеты допустимы исключительно во внутренних research-экспериментах и не должны попадать ни в обучающий конвейер поставляемой модели, ни в публикуемые продуктовые метрики.

**Дисциплина лицензий (итог):** для CARS пригодны только **CC BY 4.0** (Nomeroff-пакеты, AY000554) и **MIT** (CCPD). Все NC/ND/research-only — заблокированы. Kaggle-зеркало остаётся `unclear` до ручной проверки лицензии на странице.
