# Аналоги датасета «MAD-Cars: Multi-view Auto Dataset (Yandex)» для задачи «Color — классификация цвета кузова ТС»

> **См. также:** исходный датасет — [mad_cars.md](../about_datasets/mad_cars.md) · индекс датасетов — [datasets.md](../../datasets.md) · сводка исследования — [00_SUMMARY.md](00_SUMMARY.md)

## Контекст и требования

**Целевая модель:** `bae_model_f3` — ONNX-классификатор цвета кузова ТС. Архитектура EfficientNet-B3, вход 384×384 RGB, на выходе логиты на **15 классов**: `beige, black, blue, brown, gold, green, grey, orange, pink, purple, red, silver, tan, white, yellow`. Нормализация ImageNet из §6.5 (mean=[0.43, 0.40, 0.39], std=[0.27, 0.26, 0.26]).

**Исходный датасет:** MAD-Cars (Yandex Research, 2025) — ~70K автомобилей, 5.88M кадров 1920×1080, цвет задан hex-значениями (14/15 классов CARS; `tan` слит с beige/brown; `pink` крайне редкий ≈0.015%). Лицензия **CC BY-NC-SA 4.0** — некоммерческая, для коммерческого продукта CARS только **internal benchmark** (см. `docs/about_datasets/mad_cars.md`).

**Что нужно от аналога:**
- Покрытие таксономии 15 классов CARS (или максимально близкое подмножество), приоритет — дефицитные у MAD-Cars `tan` и `pink`.
- Кропы ТС (либо bbox для построения кропов) под прямой инференс 384×384; full-frame требует детектора (TrafficCamNet) и наследует его ошибки.
- Домен ближе к бортовому/придорожному POV CARS (дистанция 5–50 м, угол 0–30°, день/ночь), желательно adverse-условия.
- **Критично (продукт коммерческий):** явно коммерчески-совместимая лицензия для обучения/публикации метрик. По умолчанию любая лицензия считается «restricted/unclear», пока обратное не подтверждено документально и не пройдёт legal review.

> **Замечание о face embedding (для сравнения со смежными кампаниями стека CARS):** датасеты вида WIDER FACE содержат только bbox лиц **без identity-меток** и для обучения эмбеддингов лиц непригодны — без идентичностей нельзя сформировать positive/negative пары или метрик-лосс. Для color-задачи это неактуально, но отмечается для единообразия методологии: аналог должен нести именно ту метку, под которую обучается/валидируется целевая модель (здесь — класс цвета на изображении-кропе).

## Обзор аналогов

### VCoR (Vehicle Color Recognition) Dataset (Kezebou, 2021)
**2021 / ~10,5K изображений, 15 классов (split 7.5K/1.5K/1.5K) / Лицензия: custom «research and education» (комм.: unclear → по умолчанию запрещено) / folder-per-class кропы / web/mixed домен**

- **Плюсы:**
  - Точное совпадение таксономии — все 15 классов CARS 1:1, включая `tan` (которого нет отдельным классом в MAD-Cars) и `pink`. **Подтверждено**: класс-лист выведен из топ-15 цветов CarMax (white, black, grey, silver, red, blue, brown, green, beige, orange, gold, yellow, purple, pink, tan).
  - Уже кропы автомобилей + готовый train/val/test → минимальный препроцессинг: ресайз в 384×384 и прямой инференс, детектор/кроп не нужен.
  - folder-per-class совпадает со схемой Chen 2014 → единый pipeline валидации.
  - Свободно скачивается с Kaggle без agreement/email-запроса; ссылка на 2026-06-05 рабочая.
- **Минусы:**
  - Лицензия НЕ открытая и неоднозначная: на Kaggle «Data files © Original Authors», в описании — «freely available for research and education purposes». Стандартного SPDX-идентификатора (CC-BY/MIT/Apache) нет. Прямого подтверждения коммерческого разрешения веб-проверкой получить не удалось → по умолчанию коммерцию считать **запрещённой**.
  - Домен не бортовой: смешанные ракурсы/источники (часть web), нет гарантии дистанции/угла, нет явных night/IR.
  - Дисбаланс редких классов (`pink`/`tan`/`gold`) — учитывать при per-class метриках.
  - Происхождение исходных изображений и их собственные права автором не детализированы — дополнительный legal-флаг.
- **Применимость для валидации:** ОСНОВНОЙ открытый валидационный набор для `bae_model_f3` — единственный с полным покрытием 15 классов и готовыми кропами. Только **internal benchmark до legal review** лицензии.
- **Применимость для обучения:** технически идеален для (пере)обучения 15-классового классификатора, НО заблокирован неясной лицензией — нельзя без письменного разрешения автора / legal review.

### UFPR-VCR Dataset (Lima et al., SIBGRAPI 2024)
**2024 / 10 039 изображений, 9 502 ТС, 11 классов / Лицензия: academic-only non-commercial, по подписанному agreement (комм.: forbidden) / классификация (метка цвета на изображение) / surveillance/ALPR (Бразилия), включая ночь**

- **Плюсы:**
  - Современный (2024), специально под adverse conditions: ночь, окклюзии, плохое освещение — прямой стресс-тест robustness `bae_model_f3`.
  - Frontal+rear surveillance POV ближе к эксплуатации CARS, чем web-кропы.
  - >90% меток верифицированы по номерным знакам исходных ALPR-датасетов — высокое качество разметки.
  - 11/15 классов CARS покрыты (`beige, black, blue, brown, gray, green, orange, red, silver, white, yellow`); есть опубликованный benchmark.
- **Минусы:**
  - **Подтверждено веб-проверкой:** «released for academic research only … for non-commercial purposes»; доступ только по подписанному соглашению с университетской почты (gelima@inf.ufpr.br, выдача 1–5 раб. дней). Для коммерческого CARS блокер и по лицензии, и по способу доступа.
  - Нет `gold, pink, purple, tan`.
  - Бразильский трафик/номера — возможен лёгкий гео-сдвиг распределения цветов/моделей.
- **Применимость для валидации:** сильный набор для adverse/night robustness на 11 классах, но только в academic/non-commercial контексте; в коммерческой кампании CARS использовать нельзя.
- **Применимость для обучения:** запрещено лицензией (non-commercial); только академические эксперименты/абляции.

### DataCluster Labs — Vehicle Color Detection (Roboflow Universe, 2023)
**2023 / preview ~6K изображений (полный набор больше, платно) / Лицензия: CC BY 4.0 на preview; full + коммерция — платная лицензия DataCluster (комм.: preview — да при атрибуции; full — только по платному договору) / object detection (COCO/YOLO/VOC/TFRecord) / real-world crowdsourced**

- **Плюсы:**
  - Единственный кандидат с явной коммерчески-совместимой лицензией на публичную часть (CC BY 4.0 на preview) — пригоден для коммерческого продукта при атрибуции.
  - Bbox-аннотации (COCO/YOLO/VOC) → можно строить crop-pipeline без отдельного детектора.
  - Реальные краудсорс-сцены (2000+ локаций, day/night, разные дистанции), не студийные web-фото.
  - Есть путь к расширению через покупку полной коммерческой лицензии (sales@datacluster.ai).
- **Минусы:**
  - **Не подтверждено веб-проверкой:** точный набор и число цветовых классов — карточка Roboflow на 2026-06-05 отдаёт HTTP 403, перечислить классы не удалось; покрытие 15 классов CARS вероятно **неполное** и требует проверки выгрузкой.
  - Веб-проверка уточняет: коммерческое использование значимого объёма требует **платной лицензии**; «свободный» CC BY 4.0 относится лишь к небольшой preview-части (~6K).
  - Это detection-датасет: метка цвета как класс bbox, маппинг на 15-классовую классификацию строить вручную.
  - Качество/баланс цветовых меток независимо не верифицированы.
- **Применимость для валидации:** коммерчески-чистый sanity-набор: кропы по bbox → инференс → сверка с цветом bbox. Сначала **проверить покрытие классов выгрузкой**.
- **Применимость для обучения:** по лицензии единственный, кто ДОПУСКАЕТ обучение коммерческой модели (CC BY 4.0 preview / платный тариф); бесплатного объёма мало — для серьёзного обучения брать платную лицензию.

### Chen 2014 Vehicle Color Recognition (Feature Context, IEEE TITS)
**2014 / 15 601 изображение, 8 классов / Лицензия: не указана (комм.: unclear) / folder-per-class, full-frame 1920×1080 frontal / surveillance/urban road**

- **Плюсы:**
  - Уже задокументирован в проекте (`docs/about_datasets/chen_2014_color.md`) — известный baseline для 7 «лёгких» цветов.
  - Разрешение 1920×1080 и условия (urban road, haze, illumination) близки к §5.1 CARS.
  - Большой объём (15.6K) на 8 классах → статистически устойчивые per-class метрики для покрытых цветов.
  - Нет лика с `bae_model_f3` (модель кастомная).
- **Минусы:**
  - Покрытие лишь 7/15 классов CARS (`black, blue, green, grey, red, white, yellow`); нет `beige, brown, gold, orange, pink, purple, silver, tan`.
  - Класс `cyan` вне таксономии CARS — отбрасывать.
  - Full-frame, не кропы → метрика цвета наследует ошибки детекции (нужен TrafficCamNet).
  - Лицензия не указана; оригинальный IP-host нестабилен, нужны зеркала.
- **Применимость для валидации:** дополнительный набор для 7 базовых цветов в реалистичных дорожных условиях; вторичный к VCoR/MAD-Cars.
- **Применимость для обучения:** возможен как доп. источник для 7 цветов, но мал по покрытию и неясен по лицензии — не самостоятельная база.

### VeRi-776 (Vehicle Re-Identification, BUPT)
**2016 / ~50K изображений, 776 идентичностей, ~10 цветов в атрибутах / Лицензия: non-commercial, по email-agreement (комм.: forbidden) / ReID-разметка (bbox, attributes, plates) / urban surveillance**

- **Плюсы:**
  - Реальные surveillance-кропы ТС с цветовыми атрибутами — домен близок к CARS.
  - Большой объём, разные ракурсы/20 камер → robustness к viewpoint.
  - Включает «сложные» цвета (`brown, silver, orange`).
- **Минусы:**
  - **Подтверждено веб-проверкой:** доступ по email-запросу (xinchenliu@bupt.cn) с указанием аффилиации, «non-commercial purposes», запрет передачи третьим лицам и публикации — блокер для коммерческого CARS. Канонические репозитории — `VehicleReId/VeRi` и `JDAI-CV/VeRidataset`.
  - Цвет — вторичный ReID-атрибут (~10 классов), таксономия ≠ 15 классам CARS, баланс под color-классификацию слабый.
- **Применимость для валидации:** только academic/non-commercial; вторичная проверка robustness цвета к ракурсу.
- **Применимость для обучения:** запрещено лицензией.

### CompCars (Comprehensive Cars, CUHK MMLAB)
**2015 / ~208K изображений (цвет только в surveillance-части ~50K) / Лицензия: non-commercial research agreement MMLAB (комм.: forbidden) / bbox + model + color (surveillance) / web + surveillance**

- **Плюсы:**
  - Surveillance-часть даёт дорожные кропы с цветом и bbox — пригодно для crop+color pipeline.
  - Очень большой и зрелый датасет, широко цитируется; совмещает make/model/color.
- **Минусы:**
  - **Подтверждено веб-проверкой:** «Researcher shall use the Database only for non-commercial research», требуется подписанный agreement, MMLAB вправе отозвать доступ — блокер для коммерческого CARS.
  - Цвет — только в surveillance-части и как второстепенный атрибут; таксономия ≠ 15 классам CARS.
  - Web-часть без цвета — большая доля объёма задаче не помогает.
- **Применимость для валидации:** только academic/non-commercial.
- **Применимость для обучения:** запрещено лицензией.

### VehicleX (synthetic, Unity; ECCV 2020 / TPAMI 2023)
**2020 / 1 362 3D-модели (генерация произвольного объёма) / Лицензия: НЕ определена — LICENSE-файла нет (комм.: unclear → запрещено по умолчанию) / XML-метки (orientation/light/distance/type/color) / синтетика (Unity render)**

- **Плюсы:**
  - Полный контроль над цветом, ракурсом, освещением, дистанцией — можно генерировать балансные данные под все 15 классов и под бортовой POV.
  - Закрывает дефицит редких цветов (`pink/tan/gold`); неограниченный объём; точные ground-truth метки.
- **Минусы:**
  - **Подтверждено веб-проверкой:** в репозитории `yorkeyao/VehicleX` LICENSE-файл отсутствует (GitHub API на запрос лицензии отдаёт 404). Права на 3D-ассеты/Unity не прояснены — серьёзный legal-флаг; коммерцию считать запрещённой.
  - Синтетика: sim-to-real gap, рендер-цвет может расходиться с реальными металликами/бликами — слабая чистая валидация.
  - Требует Unity-пайплайна — высокий порог входа.
- **Применимость для валидации:** не первичная (синтетика); возможен как контролируемый стресс-тест для абляций.
- **Применимость для обучения:** потенциально ценен для аугментации (балансировка редких цветов, доменная рандомизация), НО только после прояснения лицензии на ассеты.

### Stanford Cars (контрольный анти-пример — БЕЗ меток цвета)
**2013 / 16 185 изображений, 196 классов Make/Model/Year / Лицензия: custom «ImageNet-like», комм. явно не разрешена (комм.: unclear) / класс = Make+Model+Year, bbox; меток ЦВЕТА НЕТ / web-каталожный домен**

- **Плюсы:** большой и чистый по make/model (полезен для VehicleMakeNet); существуют форки (`stanford_cars_refined`) с добавленным цветом — теоретический источник доразметки.
- **Минусы:** в оригинале НЕТ меток цвета → для `bae_model_f3` напрямую непригоден; web-каталожный домен далёк от бортового POV; лицензия «ImageNet-like», коммерция не разрешена явно; форки имеют собственный неясный статус.
- **Применимость для валидации:** не применим (нет цветовых меток). Анти-пример, чтобы исключить из шорт-листа.
- **Применимость для обучения:** не применим (нет меток цвета в оригинале).

## Рекомендации

**Главный вывод по таксономии (подтверждён):** единственный открытый датасет с ПОЛНЫМ покрытием всех 15 классов CARS (включая дефицитные `tan` и `pink`) — **VCoR** (~10.5K кропов, готовый split, класс-лист выведен из топ-15 CarMax). Он лучший по совместимости с `bae_model_f3` и минимальному препроцессингу.

**Главный вывод по лицензиям (critical, продукт коммерческий):** подавляющее большинство профильных color-датасетов — **non-commercial / research-only** и блокируют коммерческое использование: UFPR-VCR, VeRi-776, CompCars (все подтверждены веб-проверкой), MAD-Cars (CC BY-NC-SA). Их допустимо использовать лишь как internal/academic benchmark, но НЕ для обучения коммерческой `bae_model_f3` и НЕ для публикации метрик в маркетинге. VCoR, Chen 2014, VehicleX, Stanford Cars имеют **неуказанную/неподтверждённую** лицензию — тоже legal-флаг (по умолчанию запрещено). Единственный с явно коммерчески-совместимой лицензией — **DataCluster Labs** (CC BY 4.0 на preview ~6K; полный объём — платная лицензия), но покрытие 15 классов веб-проверкой подтвердить не удалось (карточка отдаёт 403).

**Что брать для ВАЛИДАЦИИ:**
1. **VCoR — приоритет №1**, как internal benchmark на полные 15 классов (прямой инференс 384×384). **Обязательное условие: legal review** лицензии до любой публикации метрик.
2. **DataCluster/Roboflow (CC BY 4.0 preview)** — параллельный коммерчески-чистый sanity-набор. Сначала выгрузить и проверить фактическое покрытие цветовых классов.
3. **Chen 2014** — вторичный для 7 базовых цветов в дорожных условиях (уже в проекте).
4. **UFPR-VCR / VeRi-776** — только в academic/non-commercial абляциях robustness (ночь/ракурс), вне коммерческой кампании.

**Что брать для ДООБУЧЕНИЯ (FINAL_REPORT рекомендация №4):**
- Безопасных открытых данных мало. Единственный коммерчески-совместимый источник — **платная лицензия DataCluster Labs**; альтернатива — собрать/разметить собственный 15-классовый датасет (целевой объём см. CP3-расширение в `chen_2014_color.md`).
- VeRi-776 / CompCars / UFPR-VCR / MAD-Cars обучать коммерческую модель **НЕ разрешают**.
- VCoR и VehicleX — только после письменного разрешения / прояснения лицензии; без этого в коммерческую поставку не идут.

**Явный приоритет:** валидация — **VCoR** (после legal review), коммерческая чистота — **DataCluster/Roboflow**; обучение — **платный DataCluster** либо собственная разметка.
