# Аналоги датасета «Stanford Cars Dataset» для задачи «Type — классификация типа кузова/класса ТС»

> **См. также:** исходный датасет — [stanford_cars.md](../about_datasets/stanford_cars.md) · индекс датасетов — [datasets.md](../../datasets.md) · сводка исследования — [00_SUMMARY.md](00_SUMMARY.md)

> Документ подготовлен в рамках исследования открытых датасетов-аналогов стека CARS.
> **CARS — коммерческий продукт.** Лицензионный статус каждого кандидата трактуется консервативно: пока коммерческое использование не подтверждено первоисточником явно, оно считается **запрещённым/неясным (restricted/unclear)**. Любое включение датасета в прод-обучение или дистрибуцию модели требует отдельного legal review.

---

## Контекст и требования

**Целевая модель — VehicleTypeNet** (NVIDIA TAO): классификатор на базе ResNet18, вход — кроп ТС **224×224**, выход — класс типа кузова из набора **coupe / sedan / SUV / van / truck / largevehicle** (6 классов). Задача в пайплайне CARS — после детекции ТС определить укрупнённый тип кузова для сценариев контроля доступа, мониторинга парковки и логистики (дистанция 5–50 м, ракурс ~0–30°, день/ночь).

**Исходный датасет — Stanford Cars** (16 185 изображений, 196 классов Make/Model/Year, лицензия ImageNet-подобная **non-commercial research-only**). Проблема: метки Stanford Cars — это *make/model/year* (например, `2012_BMW_M3_coupe`), а **не тип кузова**. Тип в валидации CARS извлекался суррогатным keyword-маппингом по строке модели, что дало низкую метрику (FAIL, top1 ≈ 0.3575) — частично из-за неточности маппинга, частично из-за каталожного домена (студийные/обзорные фото вместо дорожной/бортовой съёмки). Кроме того, Stanford Cars не покрывает классы `van` и `largevehicle`.

**Что нужно от аналога:**
1. **Нативная метка типа кузова** (а не суррогат из make/model) — снимает главную причину FAIL.
2. **Покрытие классов VehicleTypeNet**, в идеале включая отсутствующие в Stanford `van` и `largevehicle`.
3. **Доменная близость к бортовому/надзорному сценарию** (реальные дорожные камеры, разные ракурсы, день/ночь), а не каталожные фото.
4. **Коммерчески-чистая лицензия** — критично для прод-модели CARS; для внутренней (non-public) валидации допустимы и NC-датасеты, но без публикации метрик.
5. Формат — image-level метка под классификатор; кропы приводимы к **224×224**.

> Примечание по смежной задаче face embedding: для обучения **эмбеддингов лиц** датасеты без идентичностей (identity) непригодны — в частности **WIDER FACE** содержит только bbox лиц без меток личности и годится исключительно для детекции лиц, но **не для обучения face embedding**. Это ограничение здесь упомянуто для полноты стека CARS; на задачу Type оно не влияет.

## Обзор аналогов

### VTID2 — Vehicle Type Image Dataset (Version 2)
**2023 (v3, Data in Brief 2024) / 4 356 изображений, 5 классов / Лицензия: CC BY 4.0 (комм.: да) / Формат: image-level метка (каталоги по типу) / Домен: дорожная съёмка, Таиланд**

Подтверждено первоисточником: на Mendeley Data (DOI 10.17632/htsngg9tpc.3) явно указана лицензия **CC BY 4.0**, статья Data in Brief (PMC10859268) подтверждает «open access under the CC BY license». Датасет доступен к скачиванию. Состав: sedan 1230, pick-up 1240, SUV 680, hatchback 606, other 600.

- **Плюсы:**
  - Единственный кандидат с **явной коммерчески-разрешённой лицензией** (CC BY 4.0, при указании атрибуции) — пригоден для прод-CARS без legal review.
  - **Нативная метка типа кузова** — снимает суррогатность Stanford.
  - Реальные дорожные снимки (не каталог) — доменно ближе к бортовому сценарию.
  - Image-level формат под 224×224 классификатор из коробки.
- **Минусы:**
  - Малый объём (4 356) — недостаточно для полноценного дообучения.
  - Только 5 классов, неполное пересечение: нет coupe / van / largevehicle; pickup нужно маппить в truck.
  - Гео-смещение к парку ТС Таиланда (локальные модели, правый руль) — возможен domain gap.
  - Класс `other` разнороден — шум при маппинге.
- **Применимость для валидации:** **РЕКОМЕНДУЕТСЯ** как чистый, коммерчески-разрешённый валидационный набор по типу кузова (sedan / suv / pickup→truck) — лучшая замена проблемной суррогатной Stanford-валидации.
- **Применимость для обучения:** подходит для лёгкого дообучения/калибровки на коммерчески-чистых данных, но объёма мало для основного обучения; использовать как добавку.

### BIT-Vehicle Dataset
**2015 / 9 850 изображений (≈10 053 ТС), 6 классов / Лицензия: не указана явно (комм.: unclear) / Формат: bbox + тип (на практике image-level тип) / Домен: дорожные/въездные камеры, Китай**

Состав подтверждён: Bus, Microbus, Minivan, Sedan, SUV, Truck. Лицензия первоисточником **не оформлена** — официальная раздача через институтскую страницу BIT (`iitlab.bit.edu.cn/mcislab/vehicledb/`), не через Kaggle; коммерческий статус неясен, требуется запрос авторам / legal review.

- **Плюсы:**
  - Таксономия 6 типов почти **1:1 с VehicleTypeNet**; в эвалуаторе CARS уже заготовлен маппинг `BIT_TO_TYPENET` (bus/microbus→largevehicle, minivan→van, sedan→sedan, suv→suv, truck→truck) — датасет изначально планировался под Type.
  - Покрывает `largevehicle` (bus/microbus) — класс, отсутствующий в Stanford.
  - Реальные дорожные кадры (не каталог) — лучше доменно, чем Stanford.
  - Компактен, удобен для быстрой валидации классификатора типа.
- **Минусы:**
  - **Лицензия не подтверждена** первоисточником — коммерческий статус неясен (риск для прод-CARS).
  - Доступ через институтскую страницу BIT может быть нестабилен (исторически в кампании CARS были проблемы с доступом).
  - Сильный дисбаланс классов (sedan 5922 против minivan 476).
  - Китайский парк ТС, фронтально-верхний ракурс камеры (не строго бортовой 0–30°).
- **Применимость для валидации:** лучший по таксономии кандидат для **внутренней** валидации типа (готовый маппинг 6→6, нативные метки) — пригоден сразу после подтверждения доступа/условий. Метрики не публиковать до прояснения лицензии.
- **Применимость для обучения:** хорош для дообучения по типу при подтверждении лицензии; дисбаланс требует балансировки/аугментации. Без ясной лицензии в коммерческий прод не включать.

### MIO-TCD Classification Dataset
**2018 / 648 959 кропов (classification-часть), 11 классов / Лицензия: CC BY-NC-SA 4.0 (комм.: нет) / Формат: image-level метка / Домен: трафик-надзор, Канада/США**

Лицензия **подтверждена на официальной странице** `tcd.miovision.com`: «Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International License» — коммерческое использование **запрещено**. Полный MIO-TCD ~786k изображений (+ localization-часть с bbox).

- **Плюсы:**
  - Огромный объём готовых кропов (>648k) — идеален по масштабу.
  - **Самый близкий домен**: реальные дорожные/надзорные камеры, день/ночь, разные ракурсы и дистанции.
  - Грузовики/фургоны/автобусы хорошо представлены — закрывает `truck/van/largevehicle`.
  - Готовый image-level формат, минимальный препроцессинг.
- **Минусы:**
  - **CC BY-NC-SA: коммерческое использование ЗАПРЕЩЕНО** — blocker для прод-CARS (та же проблема, что у Stanford).
  - Таксономия трафик-надзора не совпадает с VehicleTypeNet: легковые свёрнуты в `car` (нет раздельных sedan/suv/coupe), несколько подтипов truck.
  - Кропы трафик-камер часто низкого разрешения и под наклоном — нужна чистка под 224×224.
  - Есть нерелевантные классы (pedestrian, bicycle, non-motorized, background).
- **Применимость для валидации:** условно — внутренний (non-public) срез по укрупнённым типам (truck/van/bus→largevehicle), без публикации метрик и коммерческого использования; маппинг неполный.
- **Применимость для обучения:** технически отличен по объёму и домену, но **не для коммерческого продукта** из-за NC-лицензии.

### CompCars (Comprehensive Cars)
**2015 / 136 726 изображений целых ТС, 12 типов кузова / Лицензия: custom non-commercial research-only (комм.: нет) / Формат: bbox + атрибут car type (model-level) / Домен: web-каталог + surveillance**

Лицензия **подтверждена на CUHK mmlab**: «available for non-commercial research purposes only», явный запрет на коммерческое использование и распространение изображений и производных данных. 12 типов (MPV, SUV, hatchback, sedan, minibus, fastback, estate, pickup, sports, crossover, convertible, hardtop); тип — атрибут *модели*, не пер-изображения.

- **Плюсы:**
  - Богатая таксономия 12 типов — хорошо ложится на 6 классов VehicleTypeNet (полнее Stanford).
  - Большой объём (136k), разнообразие ракурсов; есть surveillance-срез (front-view).
  - Нативный атрибут типа (model-level) — точнее суррогатного keyword-маппинга Stanford.
- **Минусы:**
  - **Non-commercial research-only — ЗАПРЕЩЕНО** для прод-CARS (тот же barrier, что у Stanford).
  - Тип — атрибут МОДЕЛИ, не изображения; нужен справочник model→type, неполное покрытие в оригинале (968/1716 моделей).
  - Web-часть каталожная (тот же domain gap, что у Stanford).
  - Гео-смещение к китайскому/азиатскому парку ТС.
- **Применимость для валидации:** только внутренняя non-public диагностика путаниц по типам; метрики не публиковать.
- **Применимость для обучения:** **не для коммерческого продукта** (NC-лицензия).

### BoxCars116k
**2017 / 116 286 изображений (27 496 ТС) / Лицензия: явно не оформлена, код «research only» (комм.: unclear) / Формат: изображения + 3D bbox + классификационные splits (есть body-type split) / Домен: трафик-надзор, произвольные ракурсы, Чехия**

README репозитория (`github.com/JakubSochor/BoxCars`) подтверждает: код «for research only purposes», **формального файла лицензии на датасет нет**; наличие отдельного **body-type split** (наряду с make-split) подтверждено. Коммерческий статус неясен — нужен запрос авторам (FIT VUT Brno).

- **Плюсы:**
  - Большой объём (116k) с надзорного домена и **любых ракурсов** — лучший домен-fit для бортового сценария среди крупных датасетов.
  - Есть **готовый body-type split** — нативная разметка типа без суррогатного маппинга.
  - Реальные трафик-камеры, разные viewpoints/освещение.
- **Минусы:**
  - **Лицензия не оформлена** (код «research only») — коммерческий статус неясен, blocker до legal review.
  - Точный состав body-категорий и их маппинг на 6 классов VehicleTypeNet первоисточником не верифицирован.
  - Европейский (чешский) парк ТС — возможен gap.
  - Качество/размер кропов варьируются — нужна чистка под 224×224.
- **Применимость для валидации:** перспективен по нативному body-split на надзорном домене, но только после уточнения лицензии и состава классов; для внутренней оценки домен близок к целевому.
- **Применимость для обучения:** большой и доменно-релевантный, но коммерческое использование не подтверждено — без legal-проверки в прод не включать.

### VeRi-776
**2016 / ~50 000 изображений (776 идентичностей ТС, 20 камер) / Лицензия: non-commercial + доступ по email (комм.: нет) / Формат: Re-ID (bbox + атрибуты type/color/brand + ID) / Домен: городской трафик-надзор**

Тип — вторичный атрибут Re-ID-датасета; доступ gated (email-запрос). Non-commercial.

- **Плюсы:**
  - Реальный городской трафик-надзор, разные ракурсы/освещение — доменно ближе к бортовому, чем Stanford.
  - Нативный атрибут type (sedan/suv/van/truck/bus и др.).
  - Покрывает крупные ТС (truck/bus→largevehicle).
- **Минусы:**
  - **Non-commercial — ЗАПРЕЩЕНО** для прод-CARS; доступ gated (email).
  - Re-ID-структура (776 ID, сильное дублирование одного ТС с разных камер) → дисбаланс по типам, риск утечки между train/val при наивном делении.
  - Тип — лишь вспомогательный атрибут, грубая таксономия.
- **Применимость для валидации:** условно — внутренняя по type-атрибуту, обязательно деление по идентичностям; NC и gated-доступ ограничивают.
- **Применимость для обучения:** **не для коммерческого продукта** (NC); Re-ID-структура делает его слабым для классификатора типа.

### UA-DETRAC
**2015 / ~140 000 кадров (~1.2 млн bbox), 4 типа / Лицензия: неоднозначна, зеркала расходятся (комм.: unclear) / Формат: detection (XML, bbox + класс) / Домен: дорожный видеонадзор, Китай**

Всего 4 грубых типа: car, bus, van, others. Лицензия оригинала custom/академическая; зеркала Roboflow помечены по-разному (CC BY 4.0 vs CC BY-NC) — статус неясен.

- **Плюсы:**
  - Реальный дорожный видеонадзор с погодными/ночными условиями — хорошее доменное разнообразие.
  - Огромный объём bbox — можно нарезать много кропов.
  - Покрывает van / bus(→largevehicle).
- **Минусы:**
  - Только **4 грубых типа** — НЕ различает sedan/suv/coupe; непригоден для основных легковых классов VehicleTypeNet.
  - Лицензия неоднозначна, зеркала расходятся — коммерческий статус неясен.
  - Класс `others` — мусорная корзина (truck+прочее), шумная метка.
  - Detection-датасет: нужна нарезка кропов и фильтрация мелких/окклюдированных bbox.
- **Применимость для валидации:** ограниченно — только укрупнённые классы (van, bus→largevehicle); для sedan/suv/coupe непригоден.
- **Применимость для обучения:** слабо из-за грубой таксономии; разве что аугментация van/largevehicle при подтверждённой лицензии.

## Рекомендации

**Приоритет для замены проблемной суррогатной Stanford-валидации:**

1. **VTID2 — primary для коммерчески-чистой ВАЛИДАЦИИ.** Единственный кандидат с подтверждённой лицензией CC BY 4.0, нативной меткой типа и реальной дорожной съёмкой. Даёт честную метрику VehicleTypeNet на `sedan / suv / (pickup→truck)` без keyword-маппинга. Ограничения — малый объём (4 356) и неполное пересечение (нет coupe / van / largevehicle). Брать первым, как чистую публикуемую метрику.

2. **BIT-Vehicle — primary для ВНУТРЕННЕЙ валидации по таксономии.** Лучшее соответствие классов (6→6, готовый маппинг `BIT_TO_TYPENET` в эвалуаторе CARS), покрывает `largevehicle`. **Но лицензия не подтверждена (unclear)** — использовать только для внутренней метрики, без публикации, до прояснения условий с авторами BIT. Подтвердить доступ через институтскую страницу.

**Для дообучения (training):**

- **Коммерчески-чистый путь без legal review — только VTID2** (как добавка/калибровка; объёма мало для основного обучения).
- **Крупные доменно-близкие кандидаты (MIO-TCD, BoxCars116k, CompCars)** — отличны по объёму и домену, но **MIO-TCD и CompCars запрещены коммерчески (NC)**, а **BoxCars116k имеет неоформленную лицензию**. В прод-обучение коммерческой модели CARS их включать **нельзя без отдельного коммерческого соглашения / legal review**. Допустимы лишь для внутренних non-public экспериментов.
- **VeRi-776 и UA-DETRAC — marginal:** VeRi (NC + Re-ID-структура с риском утечки, грубый type), UA-DETRAC (4 грубых типа, не различает sedan/suv/coupe, неоднозначная лицензия). Не рекомендуются как основа.

**Лицензионная карта (сверено с первоисточниками):**
- Commercial **ALLOWED**: только **VTID2** (CC BY 4.0).
- Commercial **FORBIDDEN**: MIO-TCD (CC BY-NC-SA 4.0), CompCars (non-commercial research-only), VeRi-776 (non-commercial + gated).
- **UNCLEAR** (нужен legal review / запрос авторам): BIT-Vehicle, BoxCars116k, UA-DETRAC.

**Итог:** единственный путь к коммерчески-чистой валидации/дообучению по типу кузова без legal review — **VTID2** (мал, но чист). Для богатой по таксономии **внутренней** валидации — **BIT-Vehicle** (после подтверждения лицензии/доступа). Все прочие крупные кандидаты упираются в лицензионный барьер для коммерческого продукта CARS и требуют legal review перед любым использованием в продукте.
