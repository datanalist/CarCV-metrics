# Аналоги датасета «autoriaNumberplateDataset-2021-05-12 (VIA-аннотации, сценовые bbox номеров)» для задачи «LP Detection — детекция номерных знаков»

> **См. также:** исходный датасет — [autoria_numberplate_detection_ru.md](../about_datasets/autoria_numberplate_detection_ru.md) · индекс датасетов — [datasets.md](../../datasets.md) · сводка исследования — [00_SUMMARY.md](00_SUMMARY.md)

> Документ подготовлен в рамках исследования открытых датасетов-аналогов для стека CARS (коммерческий продукт). Все лицензии перепроверены адверсариально (WebSearch/WebFetch, июнь 2026). По умолчанию лицензия считается `restricted/unclear`, пока коммерческое использование не подтверждено первоисточником.

## Контекст и требования

**Целевая модель — `nomeroff_lpd`** (`yolov11x-keypoints-2026-01-21.pt`): детектор на базе **YOLOv11x-keypoints**, который выдаёт **bbox номерной пластины + 4 угловых keypoints** (углы пластины для последующей ректификации/перспективного выравнивания перед OCR). Исходно обучена на **UA/EU** пластинах.

**Исходный датасет — AUTO.RIA Numberplate Dataset `2021-05-12`**: 8042 полных кадра, 8651 регион, формат **VGG Image Annotator (VIA)** с полигональными (четырёхугольными) контурами пластин (4 угловые точки на пластину), лицензия **CC BY 4.0** (коммерция разрешена).

Из этого вытекают **четыре критерия отбора аналога** (в порядке важности для CARS):

1. **Коммерческая лицензия.** CARS — коммерческий продукт. Датасеты с `non-commercial`/`research-only` лицензией непригодны для обучения/валидации продуктовой модели (годятся только как академический ориентир в публикациях).
2. **Наличие 4 угловых точек пластины.** Прямое соответствие keypoint-выходу `nomeroff_lpd` (метрика по углам / OKS, дообучение pose-головы). Если в аналоге только bbox — он годен лишь для bbox-метрики (P/R/IoU), но не для keypoint-головы.
3. **Регион пластин ближе к UA/EU.** Геометрия/пропорции/раскладка EU/CIS-пластин ближе к целевому распределению. Для стадии **детекции** регион менее критичен, чем для OCR (детектор локализует пластину как объект, текст не распознаётся), но при дообучении даёт меньший доменный сдвиг.
4. **Близость домена к бортовому сценарию** (движущаяся камера, дистанция ~5–50 м, разные ракурсы 0–30°, day/night/IR).

> Примечание для смежной задачи (face embedding): WIDER FACE и подобные датасеты детекции лиц **не содержат identity-меток** и потому **не годятся для обучения эмбеддингов лиц** — только для детекции. Здесь это вне зоны LP Detection и упоминается лишь как общий принцип отбора по стеку CARS.

## Обзор аналогов

### CCPD (Chinese City Parking Dataset) — CCPD2019 + CCPD2020/CCPD-Green

**Год: 2018 (ECCV), рефайн 2019, Green ~2020 / Объём: >300k изображений (CCPD2019) + ~11–12k (CCPD-Green) / Лицензия: MIT (комм.: да) / Формат: 4 угла + bbox + текст, закодированы в имени файла / Домен: парковки г. Хэфэй, статичные камеры**

Перепроверено (WebFetch github.com/detectRecog/CCPD): MIT, >300k подтверждены; в имени файла закодированы площадь, наклон (h/v tilt), bbox (left-up + right-bottom), **четыре угловые вершины пластины (x,y)**, индексы символов, яркость, размытость; датасет доступен (Google Drive + BaiduYun с кодом).

**Плюсы:**
- **MIT — явно разрешает коммерческое использование** (редкость среди ALPR-датасетов; критично для CARS).
- **Есть 4 угловые вершины** — прямое соответствие keypoint-выходу `nomeroff_lpd`; поддерживает OKS/угловую метрику и обучение pose-головы.
- **Огромный объём (>300k)** — статистически мощная валидация и достаточный объём для дообучения/предобучения.
- Богатые challenge-сабсеты (Rotate / Tilt / Blur / FN / Weather / Challenge) — стресс-тест локализации под наклоном/перспективой, релевантно бортовому сценарию.
- Скачивается свободно, без email-агримента/институционального доступа.

**Минусы:**
- **Только китайские пластины** (1 иероглиф + буквы) — распределение текста/пропорций отличается от UA/EU; для детектора-как-объекта не блокер, но даёт доменный сдвиг при дообучении.
- Домен — **парковки со статичных камер**, не движущийся бортовой POV; ракурсы ближе, чем дорожные 5–50 м.
- Аннотации **в имени файла** (не COCO/YOLO/VIA) — требуется парсер/конвертер (тривиальный: filename → bbox + 4 угла).
- **Лицензия MIT в README относится к репозиторию/коду; на сами фотографии отдельной строки лицензии нет.** Для коммерческого дистрибутива желателен беглый legal review статуса изображений (де-факто датасет повсеместно используется как open).

**Применимость для валидации:** Высокая. P/R/IoU и угловая/OKS-метрика `nomeroff_lpd` на CCPD-Base; стресс-метрика на Rotate/Tilt/Blur. Кросс-доменная проверка (модель обучена на UA/EU → тест на CN) показывает обобщаемость локализатора.

**Применимость для обучения:** Пригоден для предобучения/дообучения keypoint-головы (есть 4 угла, объём позволяет аугментации). Рекомендуется как **кросс-доменное дополнение** к UA/EU, не единственный источник.

### UC3M-LP (UC3M License Plate detection and recognition dataset)

**Год: 2024 / Объём: 1975 изображений, 2547 ТС/пластин, 12757 символов (train 1580 / test 395) / Лицензия: ODbL-1.0 (комм.: да, с атрибуцией + share-alike) / Формат: полигоны (4 угла) в исходном JSON; готовый YOLO-скрипт даёт только bbox / Домен: дороги/город Испании, EU-пластины**

Перепроверено (WebFetch github.com/ramajoballester/UC3M-LP + скрипт `scripts/labels2yolo.py`): лицензия **ODbL-1.0** подтверждена; ~1975 изображений подтверждены; датасет доступен (GitHub + Zenodo + edatos DOI:10.21950/OS5W4Z). **Важная правка к первичному отчёту:** исходные аннотации содержат **полигональные координаты пластины (`poly_coord`)** — то есть 4 угловые точки в данных **есть**. Однако штатный конвертер `labels2yolo.py` вызывает `utils.poly2bbox(poly_coord)` и **выдаёт только YOLO-bbox**, теряя углы. Для keypoint-головы потребуется собственный конвертер polygon → 4 keypoints (углы доступны в исходном JSON).

**Плюсы:**
- **Европейские (испанские) пластины** — наиболее близкое к UA/EU распределение формата из всех коммерчески-чистых кандидатов; геометрия/пропорции EU-пластины совпадают с целевыми.
- **ODbL-1.0 разрешает коммерческое использование** (с атрибуцией и share-alike на производную базу).
- **В исходных аннотациях есть 4 угла** (полигоны) — потенциально пригоден и для keypoint-метрики/головы при собственной конвертации.
- Реальные дорожные сцены (ближе к бортовому, чем парковки CCPD); свежий (2024).
- Открыт свободно, без email-запроса; есть готовый YOLO-конвертер (для bbox-пайплайна — нулевой порог).

**Минусы:**
- **Небольшой объём (1975)** — отлично для валидации, ограничен для самостоятельного обучения тяжёлой YOLOv11x (только доменный fine-tune/добавка).
- **ODbL share-alike (copyleft на базу данных):** производная база может требовать раскрытия под ODbL — нужен legal review перед включением в коммерческий дистрибутив.
- Только Испания — один EU-субрегион, не покрывает всё разнообразие EU/UA форматов.
- Штатный YOLO-скрипт **сводит полигоны к bbox** — для keypoints нужен свой конвертер (углы в данных есть, но «из коробки» не экспортируются).

**Применимость для валидации:** Очень высокая. Целевая **EU-валидация** P/R/IoU локализации `nomeroff_lpd` на наиболее релевантном регионе; рядом с AUTO.RIA (UA) — primary EU-бенчмарк. Угловую/OKS-метрику можно считать после конвертации полигонов в keypoints.

**Применимость для обучения:** Пригоден как **EU-доменный fine-tune** (после конвертации). Объём мал — добавка, не основной корпус. Keypoint-голову можно дообучать, реализовав polygon→4 угла из исходного JSON.

### Roboflow Universe — License Plate Recognition (`roboflow-universe-projects/license-plate-recognition-rxg4e`)

**Год: ~2022–2024 (множество версий v1–v11) / Объём: ~10 125 изображений / Лицензия: CC BY 4.0 (комм.: да, с атрибуцией) / Формат: bbox (YOLOv5/v8/v11 + COCO), 1 класс, БЕЗ углов / Домен: смешанные веб/дорожные изображения разных стран**

Перепроверено (WebSearch): лицензия **CC BY 4.0** подтверждена выдачей; **уточнён объём — ~10 125 изображений** (точнее, чем «несколько тысяч» в первичном отчёте). Прямой доступ к странице блокируется (HTTP 403), детали разметки по первоисточнику не открываются.

**Плюсы:**
- **CC BY 4.0** — коммерческое использование с атрибуцией, без share-alike (как у целевого AUTO.RIA).
- Готовые YOLO/COCO экспорты — нулевой порог интеграции в Ultralytics YOLO11.
- Заметный объём (~10k) и большое сообщество, много готовых сплитов/версий — удобно для быстрого baseline.

**Минусы:**
- **Только bbox, нет 4 угловых keypoints** — непригоден для keypoint-головы `nomeroff_lpd` напрямую.
- **Происхождение и фактическая лицензия изображений не верифицируемы по первоисточнику** (на Roboflow Universe лицензию заявляет автор датасета; качество разметки переменное).
- Неконтролируемый домен/регион — слабый контроль качества как валидационного эталона.
- Страница недоступна для прямой проверки (403) — детали разметки не подтверждены первоисточником.

**Применимость для валидации:** Ограниченно. Грубая дополнительная bbox-проверка локализации, но не эталон (переменное качество разметки, неизвестный домен). Не заменяет AUTO.RIA/UC3M-LP.

**Применимость для обучения:** Дополнительный bbox-корпус для расширения/аугментации детектора (не keypoints). Перед коммерческим включением — проверить фактическую лицензию и качество разметки.

### Open Images V7 — класс «Vehicle registration plate»

**Год: V7 — 2022 / Объём: подмножество класса — несколько тысяч–десятков тысяч bbox (точное число не подтверждено первоисточником) / Лицензия: аннотации CC BY 4.0, изображения CC BY 2.0 (комм.: да, per-image проверка) / Формат: bbox, БЕЗ keypoints / Домен: очень разнородный web-краудсорс (Flickr)**

Перепроверено (WebFetch factsfigures_v7.html): аннотации **CC BY 4.0 (Google LLC)**, изображения **CC BY 2.0**, коммерческое использование разрешено с атрибуцией; **keypoint/угловой разметки в V7 нет** (есть image-level labels, bbox, маски, visual relationships, localized narratives, point-level labels). Точный объём класса «Vehicle registration plate» по статистике первоисточника **не подтверждён** — требует выгрузки метаданных (FiftyOne/официальные тулзы).

**Плюсы:**
- CC BY 4.0 (аннотации) / CC BY 2.0 (фото) — формально разрешает коммерческое использование с атрибуцией.
- Профессиональная ручная разметка bbox — высокое качество боксов.
- Большой и разнообразный пул — полезен для аугментации/проверки робастности к разнородным сценам.
- Легко выгрузить только нужный класс через FiftyOne/официальные инструменты.

**Минусы:**
- **Только bbox, нет углов** — не для keypoint-головы `nomeroff_lpd`.
- Изображения **CC BY 2.0 «per-image»** — Google советует самостоятельно проверять статус каждого фото; для коммерческого продукта это юридический нюанс.
- Неконтролируемый домен/регион — слабая релевантность бортовому сценарию CARS.
- Точный объём класса не подтверждён первоисточником без выгрузки метаданных.

**Применимость для валидации:** Ограниченно. Дополнительная bbox-валидация робастности на разнородных сценах; не целевой эталон по домену/региону.

**Применимость для обучения:** Разнообразящий bbox-корпус для предобучения/аугментации детектора (не keypoints). Проверить per-image лицензии перед коммерческим включением.

### RodoSol-ALPR

**Год: 2022 / Объём: 20 000 изображений ТС (легковые + мото), BR/Mercosul / Лицензия: research-only / non-commercial (комм.: НЕТ) / Формат: 4 угла на пластину + текст + тип / Домен: статичные toll-камеры трассы ES-060 (Бразилия)**

Перепроверено (WebSearch): **academic-only, non-commercial**; скачивание только по подписанному соглашению, email с университетского аккаунта (`.edu`/`.ac`), ответ за 1–5 рабочих дней.

**Плюсы:**
- **Есть 4 угловые точки на каждую пластину** — идеальное соответствие keypoint-выходу `nomeroff_lpd` (OKS/ректификация).
- Крупный (20k), сбалансированный, высокое качество разметки.
- Реальные дорожные сцены с тяжёлыми условиями.

**Минусы:**
- **Коммерческое использование ЗАПРЕЩЕНО** — блокер для CARS.
- Доступ только по университетскому email + соглашение — недоступно коммерческой команде.
- BR/Mercosul пластины — регион далёк от UA/EU.
- Запрет редистрибуции/модификации без разрешения VRI Lab.

**Применимость для валидации:** Технически идеален (4 угла, объём), но non-commercial лицензия делает его **непригодным для коммерческого продукта**. Только академический ориентир.

**Применимость для обучения:** **Запрещён** для обучения коммерческой модели. Не использовать в продукте CARS.

### UFPR-ALPR

**Год: 2018 (IJCNN) / Объём: 4500 размеченных изображений (150 ТС × 30 кадров), BR / Лицензия: research-only / non-commercial (комм.: НЕТ) / Формат: bbox ТС + bbox пластины + символы (без 4 углов) / Домен: БОРТОВАЯ съёмка — камера в движущемся авто**

Перепроверено (WebSearch): **academic-only, non-commercial**; download только по университетскому email + соглашение; **без разрешения VRI Lab редистрибуция, модификация и коммерческое использование незаконны**; изображения разрешены только для демонстрации в академических публикациях.

**Плюсы:**
- **Уникальный бортовой движущийся сценарий** (камера в движущемся авто) — ближайший к целевому домену CARS.
- Полная разметка bbox ТС + bbox пластины + символы, аккуратное качество.
- Хороший размер для валидации (4500 кадров).

**Минусы:**
- **Коммерческое использование ЗАПРЕЩЕНО** (и даже модификация/редистрибуция) — блокер для CARS.
- Доступ только по университетскому email + соглашение.
- **Bbox пластины без 4 угловых keypoints** — keypoint-голову напрямую не дообучить.
- BR пластины, только дневная съёмка (нет night/IR).

**Применимость для валидации:** Доменно идеален для бортового сценария, но non-commercial лицензия запрещает использование в продукте. Только академический ориентир домена.

**Применимость для обучения:** **Запрещён**. Не использовать в продукте CARS.

### OpenALPR Benchmark — EU / BR / US (endtoend)

**Год: ~2016 / Объём: десятки–сотни изображений на регион / Лицензия: AGPL-3.0 (комм.: ограниченно, сильный copyleft) / Формат: только ТЕКСТ пластины, БЕЗ bbox/углов / Домен: разнородные реальные фото ТС по регионам**

**Плюсы:**
- EU-подмножество содержит реальные европейские пластины (регион близок к UA/EU).
- Известный публичный бенчмарк, легко скачать.
- Полезен как референс на стадии OCR (`nomeroff_ocr`), не LPD.

**Минусы:**
- **НЕТ bbox и НЕТ keypoints** — непригоден для валидации/обучения детектора (только текст для end-to-end OCR).
- **AGPL-3.0** — сильный copyleft; для коммерческого продукта требует серьёзного legal review.
- Очень малый объём, нет ground-truth геометрии пластины.

**Применимость для валидации:** Для LPD практически непригоден (нет геометрии). Только косвенный end-to-end бенчмарк EU-OCR (вне зоны `nomeroff_lpd`).

**Применимость для обучения:** Непригоден для обучения детектора (нет bbox/углов).

### Russian License Plates Detector (Roboflow Universe, `ru-anrp`)

**Год: ~2023 (версия 2023-10-24) / Объём: ~2787 изображений (есть polygon-версия) / Лицензия: НЕ подтверждена (комм.: unclear) / Формат: bbox (YOLO/COCO) + заявленная polygon-версия / Домен: российские пластины, смешанные сцены**

Перепроверено (WebSearch): объём ~2787 подтверждён выдачей; **лицензия и право на коммерцию по первоисточнику НЕ подтверждены** (страница 403, поиск лицензию не вернул) — остаётся `unclear`/`restricted` по умолчанию.

**Плюсы:**
- **Российские (CIS) пластины** — близки к целевому UA/EU-распределению по региону/формату.
- Заявлена **polygon-версия** — потенциально конвертируема в 4 угловые keypoints.
- Готовые YOLO/COCO экспорты — лёгкая интеграция.

**Минусы:**
- **Лицензия и коммерческое разрешение НЕ подтверждены** — блокер до выяснения для коммерческого CARS.
- Качество разметки и происхождение изображений не верифицируемы.
- Небольшой объём (~2.8k) — скорее валидация/добавка.
- polygon-разметка не гарантированно даёт упорядоченные 4 угла для keypoint-головы.

**Применимость для валидации:** Потенциально полезен для региональной (CIS/RU) валидации, близкой к UA/EU. **Только после подтверждения лицензии** и ручной проверки разметки.

**Применимость для обучения:** Возможен как региональная добавка (polygon→4 угла) **лишь после явного подтверждения коммерческой лицензии** и аудита разметки. Иначе не включать.

## Рекомендации

Ключевые критерии для CARS: (1) коммерческая лицензия; (2) 4 угла под keypoint-голову; (3) регион ближе к UA/EU; (4) бортовой домен.

**Главный вывод по лицензиям:** лучшие по геометрии ALPR-датасеты с 4 углами (**RodoSol-ALPR**) и идеальный по домену бортовой **UFPR-ALPR** — строго **non-commercial** (доступ по университетскому email + соглашение), поэтому **непригодны для коммерческого CARS**, несмотря на технически идеальный формат и домен. Их следует держать только как академические ориентиры в research-публикациях.

**Для ВАЛИДАЦИИ `nomeroff_lpd` (приоритет):**
1. **AUTO.RIA `2021-05-12`** — основной UA-эталон (исходный датасет, CC BY 4.0, 4 угла).
2. **UC3M-LP** (ODbL, EU/Испания) — **primary EU-бенчмарк**: целевая региональная валидация P/R/IoU; угловую/OKS-метрику считать после собственной конвертации полигонов в keypoints (углы в данных есть).
3. **CCPD-Base + Rotate/Tilt/Blur** (MIT) — keypoint/OKS-метрика на огромном объёме + стресс-тест локализации под наклоном/перспективой.

**Для ДООБУЧЕНИЯ keypoint-головы (коммерчески чисто):**
1. **CCPD** (MIT, 4 угла, объём >300k) — кросс-доменное предобучение pose-головы.
2. **UC3M-LP** (после конвертации polygon→4 угла) — EU-доменный fine-tune.
3. **Russian LP Detector (ru-anrp)** — CIS-добавка, **только после подтверждения коммерческой лицензии** и аудита разметки.
4. **Roboflow rxg4e (CC BY 4.0)** и **Open Images V7 (CC BY)** — bbox-аугментация детектора (не keypoints).

**Юридические обязательства:** все коммерческие лицензии требуют корректной атрибуции; ODbL (UC3M-LP) добавляет share-alike на производную базу; CCPD MIT покрывает код/репозиторий — статус самих фотографий желателен к беглому legal review; Open Images CC BY 2.0 — per-image проверка статуса.

**Явный приоритет:** для валидации — **UC3M-LP (EU) + CCPD (keypoint/стресс) рядом с AUTO.RIA (UA)**; для обучения — **CCPD как основной коммерчески-чистый источник с 4 углами + UC3M-LP как EU-fine-tune**.
